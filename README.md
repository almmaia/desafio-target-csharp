# Desafio Target Sistemas - C#

Este repositório contém uma solução em C# para os 5 desafios da Target Sistemas.

## Desafios incluídos

1. Verificação de sequência de Fibonacci
2. Contagem de letras 'a'
3. Soma com laço while
4. Sequências lógicas
5. Desafio das lâmpadas

## Como executar

```bash
dotnet run
```

## Requisitos

- .NET 8 SDK
