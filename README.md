# Desafio técnico

Solução em C# dos três exercícios do documento.

## Exercícios

1. Calcula a comissão de cada vendedor usando as vendas do JSON fornecido: abaixo de R$ 100,00 não há comissão; abaixo de R$ 500,00, 1%; a partir de R$ 500,00, 5%.
2. Permite registrar entradas e saídas dos produtos informados no JSON. Cada movimentação recebe um identificador único e uma descrição, e o programa informa o estoque atualizado.
3. Calcula os juros simples por atraso à taxa de 2,5% ao dia, usando o valor e a data de vencimento informados.

## Executar

Requer o SDK do .NET 8.

```bash
dotnet run
```

Escolha o exercício pelo menu. No cálculo de juros, informe o valor e a data de vencimento no formato `dd/MM/aaaa`.
